# Flavor Fiesta Web Sitesi

CSS Grid kullanılarak oluşturulmuş modern bir yemek ve tarif web sitesi tasarımıdır.

## 📌 Proje Hakkında

Flavor Fiesta, temiz ve düzenli bir tarif sitesi tasarımıdır.  
Sayfa düzeni CSS Grid kullanılarak oluşturulmuştur ve şu bölümleri içerir:

- Başlık (Header)
- Tanıtım alanı (Hero)
- Öne çıkan tarifler bölümü
- Alt bilgi (Footer)

Bu proje; düzen yapısı, boşluk kullanımı, renk kontrastı ve temel arayüz tasarımı üzerine odaklanmaktadır.

## 🛠 Kullanılan Teknolojiler

- HTML5
- CSS3
- CSS Grid

## 🎯 Özellikler

- Grid tabanlı sayfa düzeni
- Üç sütunlu yapı
- Stil verilmiş hero ve featured bölümleri
- Görselli tarif kartları
- Modern ve sade footer tasarımı

## 📂 Düzen Yapısı

Sayfa düzeni şu grid-template-areas yapısını kullanır:
"header header header"
"hero featured featured"
"footer footer footer"

Bu yapı sayfa bölümlerini net şekilde ayırır ve düzenin yönetimini kolaylaştırır.

## 🚀 Amaç
Bu proje, CSS Grid pratiği yapmak ve düzen oluşturma becerilerini geliştirmek amacıyla hazırlanmıştır.
