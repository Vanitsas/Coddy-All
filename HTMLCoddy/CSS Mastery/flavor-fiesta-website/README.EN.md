# Flavor Fiesta Website

A modern food and recipe website layout built using **CSS Grid**.

## 📌 Project Overview

Flavor Fiesta is a clean and structured recipe website design.  
The layout is created using CSS Grid to organize the main sections of the page:

- Header
- Hero section
- Featured recipes section
- Footer

The project focuses on layout structure, spacing, color contrast, and basic UI styling.

## 🛠 Technologies Used

- HTML5
- CSS3
- CSS Grid

## 🎯 Features

- Grid-based page layout
- Three-column responsive structure
- Styled hero and featured sections
- Recipe cards with images
- Clean and modern footer design

## 📂 Layout Structure

The layout uses `grid-template-areas`:
"header header header"
"hero featured featured"
"footer footer footer"

This allows clear separation of page sections and improves maintainability.

## 🚀 Purpose
This project was created as part of a CSS Grid practice exercise to strengthen layout design skills.
