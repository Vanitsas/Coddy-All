# Dropdown Menu Project

A responsive dropdown menu built with HTML and CSS.

## Features
- Horizontal navigation menu
- Hover-based dropdown submenu
- Styled search input with focus effect
- CTA button with hover effect
- Structural selectors:
  - :first-child
  - general sibling (~)
  - :nth-child()

## Technologies
- HTML5
- CSS3

## What I Practiced
- Flexbox layout
- Pseudo-classes (:hover, :focus)
- Structural selectors
- Dropdown positioning
- UI styling

## Preview
This project demonstrates how to create a simple and interactive dropdown navigation menu using only CSS.
