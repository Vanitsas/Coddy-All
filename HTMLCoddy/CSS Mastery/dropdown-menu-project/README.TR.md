# Dropdown Menü Projesi

HTML ve CSS kullanılarak oluşturulmuş responsive bir açılır menü çalışmasıdır.

## Özellikler
- Yatay navigasyon menüsü
- Hover ile çalışan dropdown alt menü
- Focus efekti olan arama alanı
- Hover efektli CTA butonu
- Yapısal seçiciler:
  - :first-child
  - genel kardeş (~)
  - :nth-child()

## Kullanılan Teknolojiler
- HTML5
- CSS3

## Öğrendiklerim
- Flexbox kullanımı
- Pseudo-class yapıları
- Yapısal seçiciler
- Dropdown menü mantığı
- Arayüz tasarımı

## Önizleme
Bu proje yalnızca CSS kullanarak interaktif bir menü oluşturmayı göstermektedir.
