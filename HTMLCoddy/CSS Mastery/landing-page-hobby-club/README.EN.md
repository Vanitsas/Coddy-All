# Hobby Club Landing Page

A modern landing page built with HTML and CSS. This project focuses on layout, responsive design, and interactive UI elements.

## Features
- Hero section with call-to-action button
- Hover and active button animations
- Card-based layout
- Smooth hover effects
- Flexbox layout
- Clean and simple UI design

## Technologies
- HTML5
- CSS3
- Flexbox

## What I Practiced
- Landing page structure
- Layout design
- UI interaction
- Hover and active states
- CSS transitions and transforms

## Preview
This project demonstrates how to build a simple and modern landing page for a community or startup.
