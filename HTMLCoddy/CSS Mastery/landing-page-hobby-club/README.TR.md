# Hobby Club Landing Page

HTML ve CSS kullanılarak oluşturulmuş modern bir landing page projesidir. Bu proje, düzen (layout), kullanıcı arayüzü ve etkileşimli tasarım konularına odaklanır.

## Özellikler
- Hero alanı ve call-to-action butonu
- Hover ve aktif animasyonlar
- Kart tabanlı tasarım
- Flexbox düzeni
- Temiz ve modern arayüz

## Kullanılan Teknolojiler
- HTML5
- CSS3
- Flexbox

## Öğrendiklerim
- Landing page yapısı
- Layout tasarımı
- Hover ve active durumları
- CSS animasyonları ve geçişler
