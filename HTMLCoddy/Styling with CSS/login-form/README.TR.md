# Giriş Formu

HTML ve CSS kullanılarak oluşturulmuş basit bir giriş formu arayüzüdür.  
Bu proje, Coddy dersleri sırasında yapılan küçük bir alıştırma çalışmasıdır.

## Özellikler
- Temiz ve sade tasarım
- Flexbox ile ortalanmış yapı
- Temel form yapısı (kullanıcı adı ve şifre)

## Kullanılan Teknolojiler
- HTML5
- CSS3

## Amaç
Bu proje yalnızca pratik amaçlıdır. Herhangi bir backend bağlantısı veya form doğrulama işlemi içermez.
