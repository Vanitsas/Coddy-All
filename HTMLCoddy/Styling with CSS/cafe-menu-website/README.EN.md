# Café Menu Website (HTML & CSS Practice)
This project is a simple responsive café menu website created for learning and practice purposes.

## Purpose
- Practice HTML structure and semantic elements  
- Learn to organize content into categories (Appetizers, Main Courses, Desserts)  
- Apply basic CSS styling (fonts, colors, layout)  
- Follow step-by-step lessons on Coddy  

## Technologies Used
- HTML5  
- CSS3

## Notes
- This is a beginner-level practice project.  
- Designed to be simple, clear, and easy to expand.
