# Café Menü Websitesi (HTML & CSS Pratiği)
Bu proje, öğrenme ve pratik amaçlı oluşturulmuş basit, responsive bir café menü web sitesidir.

## Amaç
- HTML yapısını ve semantik elementleri pratik etmek  
- İçeriği kategorilere ayırmayı öğrenmek (Appetizers, Main Courses, Desserts)  
- Temel CSS stillerini uygulamak (fontlar, renkler, düzen)  
- Coddy üzerindeki adım adım dersleri takip etmek  

## Kullanılan Teknolojiler
- HTML5  
- CSS3

## Notlar
- Bu bir başlangıç seviyesinde pratik projedir.  
- Basit, anlaşılır ve geliştirilmeye uygun olarak tasarlanmıştır.
