# Tonga Web Sayfası

Bu proje, **Coddy öğrenme egzersizi** kapsamında hazırlanmıştır.

## 📌 Genel Bakış
Tonga’da balinalarla yüzme deneyimi üzerine basit bir bilgilendirme web sayfası.  
Proje, yapılandırılmış HTML ve harici CSS kullanımı ile temel responsive tasarımın uygulanmasını göstermektedir.

## Özellikler
- Sabit (fixed) navigasyon menüsü
- Başlık ve açıklamaları içeren header bölümü
- Resim ve metin içeren About bölümü
- Tablo ile iletişim bilgilerini gösteren Contact bölümü
- Harici CSS ile stil verme
- Basit responsive düzenlemeler (media query)

## Kullanılan Teknolojiler
- HTML5
- CSS3
