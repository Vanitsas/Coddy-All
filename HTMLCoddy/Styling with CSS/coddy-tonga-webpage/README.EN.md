# Tonga Webpage

This project was completed as part of a **Coddy learning exercise**.

## 📌 Overview
A simple informational webpage about swimming with whales in Tonga.  
The project demonstrates a structured HTML layout with an external CSS file and basic responsive design.

## Features
- Fixed navigation menu
- Header section with title and description
- About section with image and text
- Contact section with table
- External CSS styling
- Basic responsive adjustments (media query)

## Built With
- HTML5
- CSS3
