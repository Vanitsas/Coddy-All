# Extreme Sporlar Landing Page

Bu proje **HTML ve CSS** kullanılarak oluşturulmuş modern ve duyarlı bir landing page’dir. Amaç **mobil öncelikli tasarım, CSS değişkenleri, responsive görseller ve temiz arayüz** yapısını öğrenmektir.

## 🚀 Özellikler
- Mobil öncelikli responsive tasarım  
- Tema ve renk yönetimi için CSS değişkenleri  
- Tutarlı tipografi ve vurgu rengi  
- `<picture>` etiketi ile responsive hero görsel  
- Temiz ve sürdürülebilir kod yapısı  
- Modern hover efektleri  

## 🛠️ Teknolojiler
- HTML5  
- CSS3 (Flexbox, CSS Variables)  
- Responsive Tasarım
