# Extreme Sports Landing Page

A modern and responsive landing page built with **HTML and CSS**. This project focuses on **mobile-first design, CSS variables, responsive images, and clean UI structure**.

## 🚀 Features
- Mobile-first responsive layout  
- CSS variables for theme and color management  
- Consistent typography and accent color  
- Responsive hero image using the `<picture>` element  
- Clean, readable, and maintainable code  
- Smooth hover effects and modern UI  

## 🛠️ Technologies
- HTML5  
- CSS3 (Flexbox, CSS Variables)  
- Responsive Design
