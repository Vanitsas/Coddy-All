# Animated Navigation

This project demonstrates a simple **animated side navigation menu** built using **HTML, CSS, and JavaScript**.

When the user clicks the **Menu button**, the side navigation smoothly slides open. Clicking the **close button (×)** hides the navigation again.

## Features
- Animated side navigation
- Smooth opening and closing transition
- Clean and minimal layout
- JavaScript event handling

## Technologies Used
- HTML
- CSS
- JavaScript

## How It Works
JavaScript listens for click events on the **Menu** and **Close** buttons.  
When clicked, the width of the side navigation changes from **0** to **250px**, creating a sliding animation with CSS transitions.
