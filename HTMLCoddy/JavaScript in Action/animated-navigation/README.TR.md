# Animated Navigation

Bu proje **HTML, CSS ve JavaScript kullanılarak oluşturulmuş animasyonlu bir yan navigasyon menüsünü** göstermektedir.

Kullanıcı **Menu butonuna** tıkladığında yan navigasyon **yumuşak bir animasyonla açılır**.  
**Kapatma butonuna (×)** tıklandığında navigasyon tekrar kapanır.

## Özellikler
- Animasyonlu yan navigasyon menüsü
- Yumuşak açılma ve kapanma animasyonu
- Basit ve temiz tasarım
- JavaScript ile olay dinleyici kullanımı

## Kullanılan Teknolojiler
- HTML
- CSS
- JavaScript

## Nasıl Çalışır
JavaScript, **Menu** ve **Close** butonlarına tıklama olaylarını dinler.  
Butonlara tıklandığında navigasyon genişliği **0** değerinden **250px** değerine değiştirilir ve CSS geçişi sayesinde menü kayarak açılır.
