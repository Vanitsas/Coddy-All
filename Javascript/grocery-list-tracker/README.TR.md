# 🛒 Market Listesi Takipçisi

## 📌 Proje Hakkında

Market Listesi Takipçisi, kullanıcıların alışveriş listelerini konsol üzerinden yönetmesini sağlayan basit bir JavaScript uygulamasıdır. Bu proje, temel JavaScript konularını (diziler, fonksiyonlar ve CRUD işlemleri) pekiştirmek amacıyla geliştirilmiştir.

---

## 🚀 Özellikler

* ➕ Listeye ürün ekleme
* ❌ Listeden ürün silme
* 📋 Tüm listeyi numaralı şekilde görüntüleme
* ⚠️ Boş liste kontrolü
* 🔍 Ürün listede yoksa uyarı verme

---

## 🧠 Kullanılan Konular

* Diziler (`push`, `splice`, `indexOf`)
* Fonksiyonlar
* Koşul ifadeleri (`if/else`)
* Döngüler (`forEach`)
* Konsol çıktıları (`console.log`)

---

## 🛠️ Nasıl Çalışır

### 1. Ürün Ekleme

Listeye yeni bir ürün ekler.

Örnek:

```id="z7k3ld"
Milk added to the grocery list.
```

---

### 2. Ürün Silme

Ürün listede varsa siler, yoksa uyarı verir.

Örnekler:

```id="u2m9qp"
Bread removed from the grocery list.
Cheese is not in the grocery list.
```

---

### 3. Listeyi Görüntüleme

Tüm ürünleri numaralı şekilde gösterir.

Örnek:

```id="p5r8nt"
Grocery List:
1. Milk
2. Eggs
3. Butter
```

Liste boşsa:

```id="c9x1we"
The grocery list is empty.
```

---

## ▶️ Kullanım

Aşağıdaki kodları kullanarak fonksiyonları test edebilirsiniz:

```javascript id="d4v6sy"
viewList();
addItem("Milk");
addItem("Bread");
addItem("Eggs");
viewList();
removeItem("Bread");
viewList();
removeItem("Cheese");
```
