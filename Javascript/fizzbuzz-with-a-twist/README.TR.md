# FizzBuzz with a Twist 🚀

Bu proje, klasik FizzBuzz probleminin geliştirilmiş bir versiyonudur. JavaScript'te kontrol yapıları ve problem çözme becerilerini geliştirmek için hazırlanmıştır.

## 📌 Özellikler

* 1'den verilen sayıya kadar olan sayıları yazdırır
* Şu kuralları uygular:

  * **3'e bölünen → "Fizz"**
  * **7'ye bölünen → "Buzz"**
  * **Hem 3 hem 7 → "FizzBuzz"**
* Ek özellik:

  * İçinde **"3"** geçen (ama 3 veya 7'ye bölünmeyen) sayılar → **"Almost Fizz"**

## 🧠 Mantık

Programda şu yapılar kullanılmıştır:

* Arrow function (ok fonksiyonu)
* Koşul ifadeleri (`if / else`)
* Döngüler (`for`)
* String metodları (`includes`)
