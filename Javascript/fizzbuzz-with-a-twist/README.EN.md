# FizzBuzz with a Twist 🚀

This project is a modified version of the classic FizzBuzz problem, designed to practice control flow and problem-solving in JavaScript.

## 📌 Features

* Prints numbers from 1 to a given input
* Replaces numbers divisible by:

  * **3 → "Fizz"**
  * **7 → "Buzz"**
  * **3 and 7 → "FizzBuzz"**
* Adds a twist:

  * Numbers containing **"3"** (but not divisible by 3 or 7) → **"Almost Fizz"**

## 🧠 Logic

The program uses:

* Arrow functions
* Conditional statements (`if / else`)
* Loops (`for`)
* String methods (`includes`)
